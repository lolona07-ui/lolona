# Naver Blog Automation

Codex workspace for drafting Naver Blog posts with Playwright.

## Goal
- Open Naver Blog editor in a user-authenticated browser session.
- Insert a user-provided article, upload local image files, format headings and paragraphs.
- Save a draft only; never publish without explicit authorization.

## Important
- Do not store passwords, cookies, login tokens, or private articles in this public repository.
- A GitHub repository does not grant Codex access to your logged-in Naver browser.
- If browser session / site access is unavailable in Codex Cloud, use a local computer with Playwright and manually sign in to Naver.

## Next
Select this repository as your Codex Cloud environment. Codex can then build and test the automation code, subject to environment and website constraints.
